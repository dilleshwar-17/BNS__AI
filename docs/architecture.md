# BNS AI Architecture

## Overview
BNS AI is an AI-Native Legal Intelligence Platform for the Indian Judicial Ecosystem.
It uses a multi-layer architecture with AI orchestration at the core.

## Layers
1. **Frontend** - Vanilla JS SPA with glassmorphism design
2. **API Gateway** - FastAPI with JWT auth
3. **AI Orchestration Layer** - Multi-agent system
4. **Retrieval Engine** - Hybrid search (vector + keyword + graph)
5. **Knowledge Stores** - ChromaDB, Neo4j, PostgreSQL

## Design Principles
- AI First
- Retrieval First
- Offline First
- Source Grounded
- Explainability
