# Database Schema

## Tables
- **users** - User accounts
- **chats** - Chat sessions
- **messages** - Chat messages
- **documents** - Legal documents
- **drafts** - Legal drafts
- **audits** - Audit logs
- **feedback** - User feedback
- **analytics** - Usage analytics
- **prompts** - Prompt templates
- **templates** - Document templates

## Indexes
All foreign keys and timestamp columns are indexed for performance.
