# AI Workflows

## Chat Workflow
1. Receive query
2. Classify intent
3. Verify query quality
4. Retrieve relevant knowledge
5. Build context
6. Generate prompt
7. Route to LLM
8. Validate response
9. Format & return

## Drafting Workflow
1. Select draft type
2. Collect facts via questionnaire
3. Retrieve relevant sections
4. Build drafting prompt
5. Generate draft via LLM
6. Validate legal consistency
7. Format & export
